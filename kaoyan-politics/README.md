# 考研政治 · 学习中心

> 四科学习中心之一（同引擎：[数学二](../kaoyan-math2/README.md) / [408](../kaoyan-408/README.md) / [英语二](../kaoyan-en2/README.md) / [政治](../kaoyan-politics/README.md)）。
> **政治一站式学习应用**：马原、毛中特、史纲、思修法治、时政五门课，原理对照表 + 分析题模板。零依赖、离线可用，双击即开。

## 快速开始

1. 双击本目录 `index.html`（推荐 Chrome / Edge），无需安装、无需联网；
2. 数据自动保存在**本浏览器** localStorage（键 `kaoyan-pol.v1`），与其他三科完全独立、互不影响；
3. 满分 100（成绩曲线与得分率已按 100 分制），目标分默认 70（可在「设置与数据」修改）；
4. 默认考试日期 **2026-12-19**（2026 年 12 月初试、官方编号 2027 考研的预计时间，以研招网正式通知为准），改日期后计划自动重排。

> ⚠️ 请每周到「设置与数据 → 数据备份」导出一次 JSON 备份；换设备用「导入备份」迁移。

## 学习闭环（本应用的核心设计）

```
仪表盘看任务 → 「学习」读原理 + 自做例题 → 速查卡随手查原理对照与模板
→ 「做配套练习」只刷本课相关题 → 做错自动进错题本（1/2/4/7/15/30 天复习）
→ 「学完本课」自动标记考点 → 按套做真题录分数
```

## 政治复习建议

- 现在 → 6 月：只跟马原理解类章节（辩证法、认识论），配合本应用课程与刷题；不必开始背诵；
- 7~10 月（强化）：五门课全面过一遍，混淆概念全部入错题本；
- 11~12 月（冲刺）：背诵手册 + 速查卡默写模式过原理对照表；时政考前 1~2 个月启动；分析题用三段式模板 + 每周一套真题。

## 开发者说明

- **架构**：纯原生 HTML/CSS/JS，无外部依赖、无构建；`index.html` + `app.js` + 4 个 `data-*.js` 即全部；
- **测试**（纯 Node，当前全部通过）：
  - `node --check *.js` —— 语法校验
  - `node test.js` —— 引擎纯函数（日期 / 16 章计划 / 复习调度 / 满分 = 100）
  - `node test-data.js` —— 48 题题库结构与 16 章覆盖
  - `node test-lessons.js` —— 32 课结构、例题、配套题引用
  - `node test-formulas.js` —— 35 张速查卡结构
  - `node test-mistake.js` —— 错题自动记录（错解快照 / 选项快照 / 去重更新 / 旧数据兼容 / 持久化）
- **加内容**（改完跑对应测试自动校验）：
  - 加题：`data-q.js`；
  - 加课：`data-lessons.js`；
  - 加速查卡：`data-formulas.js`；
  - 改详解：`data-notes.js`；
  - **时政卡片需要每年更新**：直接在 `data-formulas.js` 追加当年度热点卡（标注年份），旧卡可保留作背景。
