# 考研数学二 · 学习中心

> 四科学习中心之一（同引擎：[数学二](../kaoyan-math2/README.md) / [408](../kaoyan-408/README.md) / [英语二](../kaoyan-en2/README.md) / [政治](../kaoyan-politics/README.md)）。
> 一个**零依赖、离线可用**的本地一站式学习应用：分阶段计划、教学中心、知识点详解、内置题库、艾宾浩斯错题本、公式手册、学习计时、真题成绩曲线、统计诊断、数据备份。目标只有一个——你只管学习和做题，规划与复习节奏交给它。

## 快速开始

1. 双击本目录 `index.html`（推荐 Chrome / Edge），无需安装、无需联网；
2. 数据自动保存在**本浏览器** localStorage（键 `kaoyan-math2.v1`），与其他三科完全独立、互不影响；
3. 满分 150，目标分默认 120、每日目标默认 240 分钟（均可在「设置与数据」修改）；
4. 默认考试日期 **2026-12-19**（2026 年 12 月初试、官方编号 2027 考研的预计时间，以研招网正式通知为准），改日期后计划自动重排。

> ⚠️ 请每周到「设置与数据 → 数据备份」导出一次 JSON 备份，防止清理浏览器缓存时数据丢失；换电脑 / 换浏览器用「导入备份」迁移。

## 学习闭环（本应用的核心设计）

```
仪表盘看任务 → 「学习」读概念 + 自做例题 → 「做配套练习」检验（只出本课相关题）
→ 做错自动进错题本 → 「学完本课」（考点自动标为学习中）→ 「知识点」细分掌握度
→ 次日清空待复习错题 → 按套真题录分数看走势
```

## 每天怎么用（3 分钟上手）

1. **仪表盘** → 先把「今日待复习错题」清零（数学提分的核心动作）；
2. 看「今天该学什么」→ 点 **📖 去学本课**，进入「学习」页对应课程；
3. 读「概念与方法」→ **遮住解答做例题**、展开核对 → 点「✏️ 做配套练习」做本课相关习题；
4. 点「✅ 学完本课」：本课考点自动标为「学习中」；
5. 在书上做错的题当天录入「错题本」，系统按 1/2/4/7/15/30 天安排复习；
6. 按套计时模拟真题后，把分数录入「真题卷」。

## 数学二考试范围（已内置）

- **高等数学**：函数极限连续、导数与微分、中值定理与导数应用、不定积分、定积分、定积分应用、常微分方程、多元函数微分学（数二范围）、二重积分；
- **线性代数**：行列式、矩阵、向量组、线性方程组、特征值与特征向量、二次型；
- 不含：概率论与数理统计、三重积分、曲线曲面积分、无穷级数等数一 / 数三内容。

## 数学排版说明

教学、题库与详解使用三组轻量标记，页面渲染成真正的数学样式（分数上下叠放、矩阵带括号、行列式带竖线）：

- `@{分子|分母}` → 分数，如 `@{1|2}` 显示为二分之一；
- `@m{a,b;c,d}` → 矩阵（`;` 分行，`,` 分列）；`@d{..}` → 行列式（竖线）。

错题本「详情 / 编辑」弹窗中看到标记源码属正常现象，保存即可。

## 数学二复习建议

- 提分核心是「待复习错题清零」+ 每日限时计算训练，概念看懂后立刻做题内化；
- 公式手册的「默写模式」适合每天 10 分钟过一遍高频公式（积分表、求导表、泰勒展开）；
- 真题至少两遍：第一遍按章节、第二遍按套计时，分数录入「真题卷」看走势。
