# 四科内容关联实施记录（第五批）

日期：2026-10-24。承接 [408 单章试点](implementation-progress.md)，将考点、课程、专项练习、解析和错题回看入口接入四科学习引擎，并建立可重复生成的 [内容关联覆盖报告](content-coverage.md)。

## 使用流程

1. 在「知识地图」中，每个考点保留原有掌握状态按钮，新增关联课程入口；已关联题目的考点显示「练习本考点 · N 题」。
2. 打开课程后，「本课考点与练习」列出该课的固定考点和对应专项题入口。深链接及「返回本课」会展开课程、高亮目标考点。
3. 专项练习只选择明确引用该考点的题目，进入时收起首题历史答案；提交或自行揭示答案后，解析下方显示相关考点、课程和同考点练习。
4. 错题卡增加「回看相关讲解」折叠入口；到期复习揭示解析后也能回看课程。手工错题和未关联题目不生成推断链接。

所有 420 个考点均有课程引用，因此都能回看课程；尚无专项题的考点明确显示「尚未关联专项题」。无效考点练习链接显示 0 题，不会扩大为整章或整科题库。课程配套练习仍按课程的 `quiz` 列表选题，考点专项练习按题目的 `pointIds` 选题，两者可以有交集。

## 实现与兼容

`assets/content.js` 从课程和题目的 `pointIds` 建立反向索引，统一提供 `pointLinks`、`lessonPoints`、`relatedHtml`。四科 `app.js` 通过少量适配函数接入，知识地图、课程、解析和共享错题界面使用相同的关联来源；标题、链接参数均经过转义。

考点 ID、课程 ID、题目 ID 和四科存储主键保持稳定。本批不改状态版本，不删除旧掌握状态、课程完成记录、`qz` 汇总、错题或逐次作答历史，也不为旧作答补造 `pointIds`。新增作答记录保存题目当前的明确考点引用；考点专项和搜索定位不再被记录为课程配套练习模式。

两处配套题调整会改变今后进入对应课程时使用的题集；全局计划对配套练习进度的识别也按修正后的题集计算，既有学习记录仍保留。已重新生成 `assets/plan-catalog.js`，并检查搜索索引与内容一致。保留经典脚本、本地资源和零运行依赖的使用方式。

## 内容维护与自动校验

在仓库根目录运行：

```powershell
node scripts/build-content-coverage.js
node scripts/build-content-coverage.js --check
node tests/content.test.js
node tests/coverage.test.js
```

生成器读取四科真实数据，覆盖全部 65 章，逐章列出课程覆盖、专项题覆盖、缺少专项关联的考点和未关联题 ID。只统计显式引用，多考点题在题目总数中按题 ID 计一次；不通过章节或课程配套题自动贴标签。

校验会拒绝重复 ID、空或重复的考点列表、悬空或跨章引用、无效配套题、已标注题目与配套课程考点完全无交集，以及没有课程覆盖的考点。未标注 `pointIds` 的题目仍然有效，但列入待补明细。`--check` 同时检查引用完整性和报告是否需要更新，已接入 CI。

维护内容时先核对题目、考点和课程正文，再填写稳定 ID；配套题调整后还应更新计划目录，正文变动后应更新搜索索引：

```powershell
node scripts/build-plan-catalog.js
node scripts/build-search-index.js
```
