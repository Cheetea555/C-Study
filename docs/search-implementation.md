# 第二批改进：四科统一搜索

日期：2026-10-23。承接 [首批改进](implementation-progress.md)，实现改进方案中的四科搜索与内容定位。

## 可使用的功能

- 从四科总览的搜索框、科目侧栏或手机「更多」进入 `search.html`；科目内入口默认选择当前科目，可以切换为全部科目。
- 搜索 1,200 条公开内容：420 个考点、156 节课程、368 道题、256 张速查卡。
- 课程索引包含目标、概念、例题、例题讲解和常见错误；题目包含题干、选项和解析；速查卡包含正文和提示。
- 支持科目与类型筛选、空格组合关键词、大小写和全角归一化、PV / 信号量、TLB / 快表、求导 / 导数别名。
- 标题优先于正文、正文优先于章节匹配；结果展示章节、命中字段和摘要，高亮实际命中的词。每次显示 20 条，可继续展开。
- 课程结果展开对应课程，并高亮命中段落；例题讲解命中时会展开该例题。考点和速查卡会展开所属容器并高亮目标。
- 题目结果只展示目标题，隐藏历史答案，不因导航而新增作答；返回章节题库后移除定位参数。只命中题干时不附带选项或解析摘要，命中解析时明确标注。
- 搜索条件和分页保存在 URL，可刷新、前进和后退；科目内的题目、考点、课程、速查卡链接也可直接打开。

## 文件与内容维护

| 文件 | 职责 |
|---|---|
| `search.html`、`assets/search-page.js` | 搜索表单、筛选、结果和历史导航 |
| `assets/search.js` | 文本规范化、别名、评分、摘要与安全高亮 |
| `scripts/build-search-index.js` | 从四科现有内容生成确定性的静态索引 |
| `assets/search-index.js` | 随项目提供给浏览器的公开内容索引 |
| `assets/content.js`、`assets/workspace.js` | 路由解析、展开、聚焦、高亮与搜索入口 |
| 四科 `app.js` | 重置目标筛选，展示指定题目、考点或速查卡 |
| `tests/search.test.js` | 召回、排序、数据一致性、路由和真实应用导航动作 |

修改大纲、课程、题目或速查卡后，在仓库根目录运行：

```powershell
node scripts/build-search-index.js
node tests/search.test.js
node scripts/build-search-index.js --check
```

索引只来自仓库中的公开内容，不包含学习日志、个人笔记或错题记录。浏览器只加载普通本地脚本，无需加载四科应用来搜索，也不需要 fetch、外部搜索服务或新依赖。维护者提交生成产物，最终用户无需安装 Node。

索引当前为 652,274 字节，约 637 KiB。当前电脑的 Node 单进程微基准中，100 次固定查询的耗时中位数约 0.66 ms、P95 约 1.67 ms；此数值只衡量搜索函数，不代表浏览器加载、渲染或手机性能。

课程定位使用固定课程 ID 加命中词，不修改教材文本。若后续内容删改导致命中词消失，仍会打开课程；当前没有引入正文块 ID。搜索采用短语和空格多词匹配，不包含分词、拼写纠错或语义检索。

## 本批交付时的验证记录

- 自动测试：全部 24 个脚本通过，57 个 JavaScript 文件通过语法检查，60 处本地 HTML 引用有效；CI 已增加搜索测试与生成索引过期检查。索引检查兼容 Windows 换行。
- 召回：固定查询覆盖四科、大小写与全角缩写、别名、多词、正文、无结果；全部 1,200 项可以通过自身标题召回并生成相应 ID 的跳转。
- 应用动作：四科真实函数在隔离的内存状态中验证目标筛选、隐藏旧答案、不新增作答、不改掌握状态、无效 ID 返回失败。
- 浏览器：本地 HTTP 预览实际操作总览入口、科目入口、正文回看、速查卡、考点与单题定位；验证刷新、返回、实际作答后重新打开、退出定位和分页。
- 手机：390×844 视口验证搜索筛选、分页、英语速查卡与数学考点，未发现横向溢出。
- 输入边界：页面输入 HTML 形状的查询后正常显示无结果，没有产生脚本对话框。查看的浏览器错误和警告记录为空。

浏览器交互验证使用独立本地 HTTP 预览与合成记录。`file://` 模式仅完成静态兼容检查，未完成双击文件的实际浏览器交互验证。
