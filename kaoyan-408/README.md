# 考研 408 · 学习中心

> 四科学习中心之一（同引擎：[数学二](../kaoyan-math2/README.md) / [408](../kaoyan-408/README.md) / [英语二](../kaoyan-en2/README.md) / [政治](../kaoyan-politics/README.md)）。
> **408 一站式学习应用**：数据结构 + 计算机组成原理 + 操作系统 + 计算机网络。零依赖、离线可用，双击即开。

## 快速开始

1. 双击本目录 `index.html`（推荐 Chrome / Edge），无需安装、无需联网；
2. 数据自动保存在**本浏览器** localStorage（键 `kaoyan-408.v1`），与其他三科完全独立、互不影响；
3. 满分 150，目标分默认 100（可在「设置与数据」修改）；
4. 默认考试日期 **2026-12-19**（2026 年 12 月初试、官方编号 2027 考研的预计时间，以研招网正式通知为准），改日期后计划自动重排。

> ⚠️ 请每周到「设置与数据 → 数据备份」导出一次 JSON 备份；换设备用「导入备份」迁移。

## 学习闭环（本应用的核心设计）

```
仪表盘看任务 → 「学习」读概念 + 自做例题 → 速查卡随手查高频结论
→ 「做配套练习」只刷本课相关题 → 做错自动进错题本（1/2/4/7/15/30 天复习）
→ 「学完本课」自动标记考点 → 按套做 408 真题录分数
```

## 与数学二应用的差异

- 大纲、详解、教学、题库、速查卡全部换为 408 内容；错误原因分类改为「概念不清 / 原理没懂 / 计算失误 / 记忆混淆」；
- 满分 150、目标分默认 100；考试日期默认 2026-12-19，可修改后自动重排计划；
- 引擎完全同源：艾宾浩斯错题、刷题记录、计时打卡、统计报表、备份导入导出。

## 408 复习建议

- 科目顺序：数据结构 → 计算机组成原理 → 操作系统 → 计算机网络（应用生成的计划即此顺序）；
- 408 记忆量极大：速查卡的「默写模式」+ 错题本复习队列是对抗遗忘的两条主力；
- 大题套路固定（PV 操作 / 页面置换 / Cache 计算 / 子网划分 / 指令流水线），教学中心对应课的例题就是按大题步骤写的；
- 真题（2009 年起统考）至少两遍：第一遍按章节、第二遍按套计时。
