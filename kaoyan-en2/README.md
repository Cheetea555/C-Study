# 考研英语二 · 学习中心

> 四科学习中心之一（同引擎：[数学二](../kaoyan-math2/README.md) / [408](../kaoyan-408/README.md) / [英语二](../kaoyan-en2/README.md) / [政治](../kaoyan-politics/README.md)）。
> **英语二一站式学习应用**：考纲词汇、词根词缀、长难句，完形 / 阅读 / 新题型 / 翻译 / 写作五大题型专项。零依赖、离线可用，双击即开。

## 快速开始

1. 下载完整仓库，保留本目录与根目录 `assets/` 的相对位置，再双击本目录 `index.html`（推荐 Chrome / Edge），无需安装、无需联网；
2. 数据自动保存在**本浏览器** localStorage（键 `kaoyan-en2.v1`），与其他三科完全独立、互不影响；
3. 满分 100（成绩曲线与得分率已按 100 分制），目标分默认 70（可在「设置与数据」修改）；
4. 默认考试日期 **2026-12-19**（2026 年 12 月初试、官方编号 2027 考研的预计时间，以研招网正式通知为准），改日期后计划自动重排。

> ⚠️ 请每周到「设置与数据 → 数据备份」导出一次 JSON 备份；换设备用「导入备份」迁移。

## 学习闭环（本应用的核心设计）

```
仪表盘看任务 → 「学习」读方法 + 自做例题 → 速查卡随手查句型与解法
→ 「做配套练习」只刷本课相关题 → 做错自动进错题本（1/2/4/7/15/30 天复习）
→ 「学完本课」自动标记考点 → 按套做真题录分数
```

## 英语二复习建议

- 现在 → 强化前：每天背词（艾宾浩斯节奏）+ 每天精拆 3 个长难句；
- 强化期：真题阅读逐篇精读（错题记「定位句」而非答案）；新题型专项拿满分；
- 冲刺期：翻译每日一段、作文模板背熟（速查卡默写模式）+ 每周限时一套真题录入分数。

## 开发者说明

- **架构**：纯原生 HTML/CSS/JS，无外部依赖、无构建；科目页面由 `index.html`、`app.js` 和 4 个 `data-*.js` 组成，并依赖根目录 `assets/` 中的共用样式与脚本。复制或部署时保留完整仓库结构，共用模块见 [根目录说明](../README.md#-开发)。
- **测试**（在本科目目录运行，需要 Node.js）：
  - `Get-ChildItem *.js | ForEach-Object { node --check $_.FullName }` —— PowerShell 逐文件语法校验
  - `node test.js` —— 引擎纯函数（日期 / 8 章计划 / 复习调度 / 满分 = 100）
  - `node test-data.js` —— 40 题题库结构与 8 章覆盖
  - `node test-lessons.js` —— 16 课结构、例题、配套题引用
  - `node test-formulas.js` —— 39 张速查卡结构
  - `node test-mistake.js` —— 错题自动记录（错解快照 / 选项快照 / 去重更新 / 旧数据兼容 / 持久化）
- **加内容**（改完跑对应测试自动校验）：
  - 加题：`data-q.js`；
  - 加课：`data-lessons.js`；
  - 加速查卡：`data-formulas.js`；
  - 改详解：`data-notes.js`。
